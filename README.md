# UIUX — Repository for local UI/UX prototypes

此 repo 包含多個靜態 HTML 原型與輔助腳本（位於 `crawler/`）。

快速上手

- Clone（HTTPS）：
```
git clone https://github.com/Timlin0929/UIUX.git
cd UIUX
```
- 或使用 SSH（若已設定 SSH key）：
```
git clone git@github.com:Timlin0929/UIUX.git
cd UIUX
```

常用 Git 工作流程

```
git status
git add .
git commit -m "描述你的變更"
git push origin main
```

如果需要從遠端抓取更新：
```
git pull origin main
```

注意事項
- 已在 `.gitignore` 中加入 `weather.env` 與 `weather.env.js`（不要把敏感金鑰上傳）。
- 若在新機器上遇到認證問題，請使用 `gh auth login --web` 或設定 SSH key / Personal Access Token (PAT)。
